本文件夹下的文档均与飞书开发相关，以下是其主要内容介绍：

- docs/feishu/card_json.md: 本文档介绍卡片 JSON 2.0 的整体结构和属性说明。
- docs/feishu/emoji.md: 本文列举用于表情回复的表情与相应的 emoji_type。
- docs/feishu/history_text.md: 获取指定会话（包括单聊、群组）内的历史消息（即聊天记录）。
- docs/feishu/normal_text.md: 卡片的普通文本组件支持添加普通文本和前缀图标，并设置文本大小、颜色、对齐方式等展示样式。

如果需要开发的功能不在以上文档内，可以通过网站进一步搜索(https://open.feishu.cn/document/home/index)
